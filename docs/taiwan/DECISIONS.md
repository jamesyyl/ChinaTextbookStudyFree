# DECISIONS｜臺灣教材版決策紀錄

更新：2026-10-16。
決策分為 **ACCEPTED（方向已定）** 與 **PROPOSED（需測試決定）**。接受方向不等於程式已實作。

## TW-ADR-001｜產品邊界 — ACCEPTED

**決定：** 沿用 ChinaTextbookStudyFree 的網站、操作流程、學習地圖、判分、複習與進度功能。只做台灣課綱及教材資料相容所需的最小修改。不在這個階段引入其他專案的底層規格或架構。

**理由：** 先使台灣孩子能完成一堂課，快速驗證內容與體驗。

**不做：** 新學習平台、全新推薦演算法、大量超前功能、整站 UI 重寫。

## TW-ADR-002｜教材來源與 JSON — ACCEPTED

**決定：** PDF 不是必要輸入。AI 可以直接依已整理的臺灣教材內容產生原版的 outline JSON、quiz JSON；維持 output 下的來源檔案規範，再交由 build-data.ts 組成課程。先用六上數學 U1-1，逐課驗證。

**理由：** 網站實際使用的是 JSON，不需要把大陸教材 PDF 管線當作必要步驟。

**限制：** 原版固定的檔名／出版社映射需要調整；AI 生成內容還需要驗證答案與解析。

## TW-ADR-003｜圖片按需產生 — ACCEPTED

**決定：** 沒有教學需要就不放圖片。需要時產生獨立圖片檔，以 JSON 路徑引用；不把圖片二進位塞進 JSON。一般題目的圖片欄位與呈現功能等到真正遇到需要圖片的題才補。

**理由：** 文字、選擇、填空課程先可用；避免為裝飾圖片拖慢進度。

**限制：** 原版目前只具備課文／故事圖片處理，一般 Question 尚未支援圖片。

## TW-ADR-004｜快速測試而不是大型資源建置 — ACCEPTED

**決定：** 保留原版完整 Docker 路線，另外增加輕量臺灣教材測試模式。首輪不下載約 2 GB 原版資源、不做大型 TTS 轉檔；優先讓修改 JSON 後能快速再次試學。

**理由：** 下載、音訊轉換、整站建置不應成為教材逐題修正的代價。

**限制：** 輕量指令與容器目前還不存在；原版完整 Docker 能快取大型下載層，但不能當作「完全免資源」驗收。

## TW-ADR-005｜資料變更與品質門檻 — ACCEPTED

**決定：** 修改先通過來源 JSON 檢查，再確認建置產物、判分和瀏覽器呈現。課程 ID 不得隨意改成不同內容的同名 ID；測試快取／進度與正式使用者資料分開。

**理由：** 防止遺漏課、錯誤判分或舊進度使驗收失真。

**限制：** 嚴格 validator、數學分數判分修正、測試資料隔離均待實作。

## TW-ADR-006｜快速更新的具體機制 — PROPOSED

**選項 A：** 每次來源 JSON 改動後重新資料建置 + Next.js 靜態匯出，Nginx 提供新版。
**選項 B：** 修改既有畫面，改成瀏覽器執行時載入 JSON，以支持不重新輸出 HTML 即更新題目。

**目前取向：** 先實測 A 的耗時及可靠度，若足夠快就不做 B。原版使用 output: export，單純替換 public/data 下的課程 JSON 不保證已輸出頁面立刻改變。

## TW-ADR-007｜驗收與變更紀錄 — ACCEPTED

**決定：** CURRENT_STATE 為當前真相、IMPLEMENTATION_TODO 為唯一 TODO、CHANGELOG 為每次實際修改與證據。每項 TODO 有 ID、依賴、驗收及狀態。未實測不可標通過；文件紀錄不等於產品驗收。

**理由：** 避免同一件事散落在多個對話、文檔及 PR，造成進度互相矛盾。

**執行習慣：** 優先本機檢查、減少不必要 Actions；不自行合併未經審核的工作。
